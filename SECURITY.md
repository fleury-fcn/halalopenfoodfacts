# Security Policy

## Supported Versions

This project is actively maintained on the `main` branch. Security fixes are applied there and deployed to production as soon as possible.

| Version | Supported |
| ------- | --------- |
| main    | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not open a public issue**. Instead, report it privately by emailing:

📧 **contact@halalopenfoodfacts.org**

Please include as much detail as possible:
- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any relevant logs, screenshots, or proof-of-concept code

You can expect an initial response within **72 hours**. Given this platform handles user-submitted data and runs on production infrastructure, vulnerabilities affecting data integrity, authentication, or user privacy will be treated with the highest priority.

Once the issue is confirmed, we will work on a fix and coordinate disclosure with you before any public release.

Thank you for helping keep this project and its community safe.
